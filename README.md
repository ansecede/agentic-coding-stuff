# Personal workspace

This repository stores personal defaults for development tools and AI-assisted work. It keeps shell settings, agent instructions, and custom skills in one place.

## Contents

- `.zsh_base` contains the base Zsh settings, Oh My Zsh options, plugins, history settings, and personal aliases.
- `agentic-coding/AGENTS.md` contains the global instructions for Codex and other agents.
- `agentic-coding/CLAUDE.md` contains the global instructions for Claude-based tools.
- `agentic-coding/skills/` contains custom Codex skills.
- `agentic-coding/qrspi-setup/` contains setup commands and documentation for the QRSPi workflow.

This repository is the source of truth for these settings. Update the files here, then link them into the tool-specific configuration paths.
